# ReportFlow — Monthly Reporting Platform

A front-end prototype for a monthly reporting workflow: dashboard, report management, data collection, review queue, and report generation preview.

## Run locally
Open `index.html` in a modern browser. The prototype uses sample data and browser-side interactions. It does not include production authentication or a connected database.

## Deploy with GitHub Pages
1. Upload `index.html`, `style.css`, and `app.js` to the root of a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

## Project status
This is a prototype, not a production system. Login is a demo interaction; any valid-looking email/password can enter the app. Data and workflow states are sample/client-side only.
